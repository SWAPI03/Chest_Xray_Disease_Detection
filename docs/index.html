Explainability

Grad-CAM — where the model looks

A model can be right for the wrong reasons. Grad-CAM overlays a heatmap of the regions that drove the prediction, so you can sanity-check that it's attending to lung tissue rather than edges, text, or the spine.

Architecture

How it works

Kaggle dataset→ Resize + augment→ DenseNet121→ Train→ Evaluate→ Grad-CAM
  • tf.data pipeline: decode, gray to RGB, resize to 224×224, cache, ImageNet normalisation.
  • Augmentation: horizontal flip, ±10° rotation, brightness/contrast jitter, Gaussian noise, all per image with tf ops.
  • keras.applications.DenseNet121 (ImageNet weights) → GlobalAveragePooling → Dropout → Dense(1, sigmoid).
  • class_weight in model.fit for the ~3:1 Pneumonia:Normal imbalance.
  • AdamW, cosine LR decay, mixed precision, checkpoint + early stopping on validation AUC.
Design choice

Why DenseNet121?

DenseNet121 is the backbone behind CheXNet (Rajpurkar et al., 2017), which reached radiologist-level performance on chest X-ray classification. Its dense skip connections let gradients flow cleanly to early layers and help the network pick up the fine-grained texture differences in lung tissue. A ResNet50 backbone is also supported for a faster alternative.

Reproduce

Run it yourself

Full instructions are in the repository README. The short version:

# 1 · Install dependencies
pip install -r requirements.txt

# 2 · Download the dataset (needs a Kaggle account)
kaggle datasets download -d paultimothymooney/chest-xray-pneumonia
unzip chest-xray-pneumonia.zip -d data/raw/
python data/prepare_data.py

# 3 · Train
python main.py --mode train

# 4 · Predict on a single X-ray (+ Grad-CAM)
python main.py --mode predict --checkpoint outputs/models/best_model.keras --image path/to/xray.jpg

# No data handy? Run the smoke test:
python main.py
